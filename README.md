# Clinic Management System

A Java-based clinic management system developed to simulate and optimize patient-doctor scheduling. This project demonstrates the implementation of complex data structures from scratch and advanced Object-Oriented Programming (OOP) principles.

## Features & Data Structures
* **2-3 Tree:** Implemented a balanced 2-3 search tree from scratch for highly efficient data retrieval and management.
* **Custom Queues:** Developed custom queue data structures to manage patient flow dynamically.
* **Modular OOP Design:** Utilized node interfaces (`InNode`, `Leaf`, `Nodeable`) to ensure a scalable, robust, and maintainable architecture.

## Technologies Used
* Java
* Object-Oriented Programming (OOP)
* Data Structures & Algorithms
